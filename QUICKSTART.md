# 🚀 Quick Start Guide

## ⚡ Get Your Portfolio Running in 3 Steps

### Step 1: Navigate to the Project
```bash
cd "c:\Users\Hp\OneDrive\Desktop\portfolio\My_Portfolio\mahak-portfolio"
```

### Step 2: Install Dependencies
```bash
npm install
```

### Step 3: Start the Development Server
```bash
ng serve
```

Then open your browser and go to: **http://localhost:4200**

## 🎨 Customization Quick Tips

### Update Your Information
Edit `src/app/services/portfolio.ts` to change:
- Projects
- Experience
- Services
- Skills

### Change Colors
Edit `src/styles.css`:
- Primary color: `#667eea`
- Secondary color: `#764ba2`

### Update Contact Email
Edit `src/app/components/contact/contact.ts`

---

## 📦 Build for Production

```bash
ng build --configuration production
```

Your optimized portfolio will be in the `dist/` folder ready to deploy!
